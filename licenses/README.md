# 외부 라이선스 출처

이 저장소의 코드는 MIT 라이선스(저작권자 홍서진, 루트 `LICENSE`)입니다. 아래 외부 구성 요소는 각자의 라이선스를 따르며, 전문을 이 폴더에 보관합니다.

| 파일 | 대상 | 출처 |
|---|---|---|
| THREE-MIT.txt | Three.js r128 = npm `three` 0.128.0 (빌드 때 `vendor/three.min.js`로 동봉) | https://github.com/mrdoob/three.js/blob/r128/LICENSE |
| Jua-OFL.txt | Google Fonts Jua (CSS 링크만 사용) | https://github.com/google/fonts/blob/main/ofl/jua/OFL.txt |
| NotoSansKR-OFL.txt | Google Fonts Noto Sans KR (CSS 링크만 사용) | https://github.com/google/fonts/blob/main/ofl/notosanskr/OFL.txt |
| ws-MIT.txt | ws 8.23.0 (로컬 서버 의존성) | 설치된 패키지 LICENSE |
| supabase-js-MIT.txt | @supabase/supabase-js 2.118.0 (lodestar 빌드의 `vendor/supabase.js`) | 설치된 패키지 LICENSE |

글꼴 바이너리는 동봉하지 않습니다. Google Fonts URL은 원본 그대로이며 글꼴 버전을 고정하는 URL이 아닙니다.
